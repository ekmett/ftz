# Exponential shader agreement

This manual Metal fixture runs the public shader's exponential graph against the
same input/expected packet generated by `ftz_test_exp_contract`. It requires
macOS 15 or newer, Metal, DXC with SPIR-V support, SPIRV-Tools and SPIRV-Cross.
Run it on an idle GPU. Generated shader code and packets stay in a build folder.

From the repository root, after building the CPU contract fixture:

```sh
mkdir -p build/exp-shader
build/tests/core_regression/ftz_test_exp_contract build/exp-shader/pairs.bin
xcrun clang++ -std=c++20 -O2 -fobjc-arc tests/exp_shader/metal.mm \
  -framework Foundation -framework Metal -o build/exp-shader/metal
```

Set `FTZ_NATIVE_INCLUDE` to native's source `src` directory or installed include
root. Put `dxc`, `spirv-val` and `spirv-cross` on `PATH`, then run both policies:

```sh
for policy in 0 1; do
  dxc -HV 2021 -T cs_6_6 -E exp_check -spirv -fspv-target-env=vulkan1.1 \
    -D FTZ_FP32_HARDWARE_FTZ=$policy -D FTZ_SHADER_INT64=0 \
    -I src/hlsl -I src/shared -I "$FTZ_NATIVE_INCLUDE" \
    -Fo build/exp-shader/exp-$policy.spv tests/exp_shader/exp.hlsl
  spirv-val --target-env vulkan1.1 build/exp-shader/exp-$policy.spv
  spirv-cross build/exp-shader/exp-$policy.spv --msl --msl-version 23000 \
    --output build/exp-shader/exp-$policy.metal
  build/exp-shader/metal build/exp-shader/exp-$policy.metal build/exp-shader/pairs.bin
done
```

The packet is a sequence of little-endian `uint32_t` input/result pairs. Inputs
are canonical FTZ words. NaNs compare by classification; every other output word
must match exactly. The runner reports mismatches and exits unsuccessfully if
any occur. It does not use a numerical tolerance or compare with libm.

The shader buffer-size table uses SPIRV-Cross's default Metal buffer slot 25.
The Metal compiler uses safe arithmetic and precise floating-point functions;
the emitted fused operations remain explicit. This is a device check for this
shader graph, not general admission of every FTZ arithmetic operation.
